# Sección 5: Integración con APIs de Brokers (OANDA, FXCM e Interactive Brokers)

**Instructor:** Axel Francisco Munguía Quintero  
**Clases:** 50 a 76 (~3.5 horas de contenido)

---

## 📽️ Clase 50-56: Broker FOREX y CFDs OANDA API (56:33)
- Conexión a la API de OANDA v20 REST y WebSockets.
- Extracción de datos históricos y streaming tick a tick en tiempo real.
- Creación y modificación de posiciones de compra y venta automatizadas.

## 📽️ Clase 57-63: Broker FOREX y CFDs FXCM REST API (21:40)
- Autenticación mediante Tokens de API FXCM.
- Gestión de cuentas, consulta de balance y envío de órdenes Market/Limit.

## 📽️ Clase 64-74: Interactive Brokers (IBAPI) (81:53)
- Conexión a la API mediante TWS (Trader Workstation) o IB Gateway (`ibapi` / `ib_insync`).
- Definición de contratos financieros (Acciones, Futuros, Forex, Opciones).
- Descarga de barras históricas y suscripción a ticks en tiempo real.
- Gestión avanzada de órdenes (Bracket Orders, Stop Loss, Take Profit).
- Resolución de conflictos y manejo de errores con la API de IB.

## 📽️ Clase 75-76: Selección de Broker por País (1:10)
- Criterios regulatorios (SEC, FINRA, FCA, ASIC) e impuestos por jurisdicción.
